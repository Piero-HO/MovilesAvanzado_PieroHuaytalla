# Requerimientos Funcionales

## RF-01 – Buscar estación
El sistema debe permitir al usuario buscar una estación ingresando su nombre.

## RF-02 – Consultar información de una estación
El sistema debe mostrar información de la estación seleccionada, incluyendo:
- Línea o líneas a las que pertenece.
- Estado de la estación.
- Disponibilidad de ascensor.
- Accesibilidad.

## RF-03 – Listar estaciones por línea
El sistema debe permitir consultar y mostrar las estaciones pertenecientes a una línea específica.

## RF-04 – Consultar estaciones de la Línea 2
El sistema debe permitir identificar las estaciones correspondientes a la Línea 2 y mostrar su estado.

## RF-05 – Consultar conexiones
El sistema debe mostrar las conexiones disponibles entre las diferentes líneas de transporte.

## RF-06 – Consultar conexión con el Metropolitano
El sistema debe permitir identificar las estaciones que tienen conexión o integración con el Metropolitano.

## RF-07 – Consultar destinos
El sistema debe permitir ingresar un destino y mostrar una estación recomendada para llegar a dicho lugar.

## RF-08 – Calcular una ruta
El sistema debe permitir ingresar una estación de origen y un destino para mostrar una ruta de estaciones.

## RF-09 – Validar datos ingresados
El sistema debe validar las opciones y búsquedas ingresadas por el usuario y mostrar un mensaje cuando los datos no sean válidos.

## RF-10 – Preparar el sistema para una futura aplicación móvil
La información de estaciones, líneas, conexiones y destinos debe mantenerse organizada en estructuras de datos que permitan reutilizar la lógica posteriormente en una aplicación móvil.
